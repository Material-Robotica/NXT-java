01

Clase 1 · Presentación de la misión

45 minGuía: Partes del NXT

Objetivos: presentar la misión, reconocer las partes del NXT y acordar las reglas de cuidado del equipo.

La misión. El grupo forma parte de una agencia espacial que envió un robot explorador a un planeta lejano. Desde la Tierra solo se le pueden enviar programas: el robot tiene que moverse, esquivar obstáculos, analizar el terreno y preparar la zona de aterrizaje de la próxima nave. Cada clase es una etapa de la misión.

Actividades

  1. Presentar la misión y formar los equipos (roles sugeridos: programador/a, constructor/a, responsable del registro).
  2. Recorrer las partes del ladrillo, los motores y los sensores con la tabla del tema Partes del NXT.
  3. Armar o revisar el robot base: motor izquierdo en B, derecho en C.
  4. Completar una tabla con lo que hay conectado en cada puerto.
Regla número uno

Cuidar los robots. Probar siempre dentro del área de pruebas, nunca sobre mesas sin borde, y apagar el ladrillo al terminar.

02

Clase 2 · Primer contacto con la nave

45 minGuía: Estructura, Motores

Objetivos: comprender la estructura de un programa Java para el NXT, subirlo con Ctrl + Shift + B y mover los motores por tiempo.

Misión: la base envía el primer mensaje al robot y lo hace avanzar en línea recta para comprobar que los motores funcionan.

src/MovimientoRecto.java
import lejos.nxt.*;
import lejos.util.Delay;

public class MovimientoRecto {
    public static void main(String[] args) {
        LCD.drawString("Mision iniciada", 0, 0);
        Button.waitForAnyPress();

        Motor.B.setSpeed(300);
        Motor.C.setSpeed(300);
        Motor.B.forward();
        Motor.C.forward();

        Delay.msDelay(3000);

        Motor.B.stop(true);
        Motor.C.stop();
        LCD.drawString("Prueba completa", 0, 2);
        Button.waitForAnyPress();
    }
}

Desafíos

  1. Cambiar la velocidad y el tiempo para que el robot recorra exactamente 1 metro. Anotar los valores.
  2. Hacer que avance, se detenga 1 segundo y retroceda a la posición inicial.

Clase 3 · Fundamentos del robot explorador

45 minGuía: Motores, Clase auxiliar

Objetivos: usar rotate() para movimientos precisos, calibrar el giro de 90° y usar la clase auxiliar Robot.

Misión: recorrer un circuito marcado en el piso (por ejemplo, una "L" o una "U" de cinta) sin salirse.

Primero se calibra: probar valores en girarDerecha() hasta que el robot gire exactamente 90° y guardarlo en una constante. La palabra final indica que su valor no cambia.

src/RecorridoExplorador.java
public class RecorridoExplorador {
    // grados de rueda para girar 90 grados: medir y ajustar en cada robot
    static final int GIRO_90 = 180;

    public static void main(String[] args) {
        Robot.mostrar("Circuito", 0);
        Robot.esperarBoton();
        Robot.velocidad(300);

        Robot.avanzar(1080);
        Robot.girarDerecha(GIRO_90);
        Robot.avanzar(720);
        Robot.girarIzquierda(GIRO_90);
        Robot.avanzar(1080);

        Robot.mostrar("Llegada!", 2);
        Robot.esperarBoton();
    }
}

Requiere Robot.java en la carpeta src (ver el tema Clase auxiliar).

Desafíos

  1. Calcular cuántos grados de rueda corresponden a 10 cm de avance (pista: medir cuánto avanza el robot con 360°).
  2. Diseñar un circuito propio, dibujarlo en papel con medidas y programarlo.
04

Clase 4 · ¿Cuántos lados tiene?

45 minGuía: Clase auxiliar

Objetivos: usar for y métodos con parámetros para dibujar polígonos regulares; relacionar con el ángulo exterior (360° / cantidad de lados).

Misión: el robot marca en el suelo las zonas de exploración con figuras geométricas. Se sujeta un marcador al robot, en el centro entre las ruedas.

src/DibujarFormas.java
import lejos.nxt.Button;

public class DibujarFormas {
    static final int GIRO_90 = 180;   // el valor calibrado en la clase 3

    public static void main(String[] args) {
        Robot.velocidad(250);

        Robot.pantalla("ENTER:", "triangulo", "", "");
        Button.ENTER.waitForPressAndRelease();
        poligono(3, 720);

        Robot.pantalla("ENTER:", "cuadrado", "", "");
        Button.ENTER.waitForPressAndRelease();
        poligono(4, 720);

        Robot.pantalla("Figuras listas", "", "", "");
        Robot.esperarBoton();
    }

    // lados: cantidad de lados; largo: grados de rueda por lado
    static void poligono(int lados, int largo) {
        int anguloExterior = 360 / lados;
        int giro = GIRO_90 * anguloExterior / 90;   // regla de tres
        for (int i = 0; i < lados; i++) {
            Robot.avanzar(largo);
            Robot.girarDerecha(giro);
        }
    }
}

Desafíos

  1. Dibujar un pentágono y un hexágono. ¿Qué pasa con la figura cuando los lados son muchos (por ejemplo, 36)?
  2. Elegir la cantidad de lados con LEFT y RIGHT antes de dibujar.
  3. Calcular a mano el ángulo exterior de cada figura y compararlo con lo que hace el robot.
05

Clase 5 · ¡Ayuda, estoy atascado!

45 minGuía: Sensores: contacto y ultrasónico

Objetivos: leer el sensor ultrasónico y tomar decisiones con if dentro de un while.

Misión: el terreno está lleno de rocas (cajas). El robot tiene que avanzar y, cuando detecte una roca a menos de 30 cm, girar para esquivarla. Sensor ultrasónico en el puerto 4.

src/EvitarObstaculos.java
import lejos.nxt.*;
import lejos.util.Delay;

public class EvitarObstaculos {
    public static void main(String[] args) {
        UltrasonicSensor sonar = new UltrasonicSensor(SensorPort.S4);
        Motor.B.setSpeed(300);
        Motor.C.setSpeed(300);

        while (!Button.ESCAPE.isDown()) {
            int distancia = sonar.getDistance();
            LCD.clear();
            LCD.drawString("Dist: " + distancia, 0, 0);

            if (distancia > 30) {
                Motor.B.forward();          // camino libre
                Motor.C.forward();
            } else {
                Motor.B.stop(true);         // roca: frenar y girar
                Motor.C.stop();
                Sound.beep();
                Motor.B.rotate(180, true);
                Motor.C.rotate(-180);
            }
            Delay.msDelay(100);
        }
        Motor.B.stop(true);
        Motor.C.stop();
    }
}

Desafíos

  1. Girar hacia un lado al azar: new java.util.Random().nextInt(2) devuelve 0 o 1.
  2. Agregar el sensor de contacto como respaldo, para las rocas que el ultrasónico no ve (muy bajas o muy angostas).

Clase 6 · ¡Vamos a prospectar!

45 minGuía: Sensor de luz

Objetivos: medir y calibrar el sensor de luz, y clasificar superficies con if / else if / else.

Misión: el suelo del planeta tiene minerales raros: zonas negras y zonas blancas sobre un fondo gris. El robot recorre el terreno y se detiene a "analizar" cada mineral que encuentra. Sensor de luz en el puerto 3, mirando al piso.

Antes de programar, medir con MedirLuz (tema '+ref('luz','Sensor de luz')+') los valores del negro, el gris y el blanco, y ajustar los límites.

src/Prospector.java
import lejos.nxt.*;
import lejos.util.Delay;

public class Prospector {
    public static void main(String[] args) {
        LightSensor luz = new LightSensor(SensorPort.S3);
        int limiteNegro = 30;    // ajustar con los valores medidos
        int limiteBlanco = 55;

        Motor.B.setSpeed(200);
        Motor.C.setSpeed(200);

        while (!Button.ESCAPE.isDown()) {
            int valor = luz.getLightValue();
            LCD.clear();
            LCD.drawString("Luz: " + valor, 0, 0);

            if (valor < limiteNegro) {
                Motor.B.stop(true);
                Motor.C.stop();
                LCD.drawString("MINERAL NEGRO", 0, 2);
                Sound.twoBeeps();
                Delay.msDelay(2000);
                Motor.B.rotate(360, true);   // salir del mineral
                Motor.C.rotate(360);
            } else if (valor > limiteBlanco) {
                Motor.B.stop(true);
                Motor.C.stop();
                LCD.drawString("MINERAL BLANCO", 0, 2);
                Sound.beepSequence();
                Delay.msDelay(2000);
                Motor.B.rotate(360, true);
                Motor.C.rotate(360);
            } else {
                Motor.B.forward();           // terreno comun
                Motor.C.forward();
            }
            Delay.msDelay(50);
        }
        Motor.B.stop(true);
        Motor.C.stop();
    }
}

Desafíos

  1. Contar cuántos minerales de cada tipo encontró y mostrarlo al terminar.
  2. Si el kit tiene sensor de color, detectar minerales de colores con ColorSensor y getColorID().

Clase 7 · Medir el terreno

45 minGuía: Motores, Sensores

Objetivos: usar el sensor de rotación del motor (getTachoCount()) y convertir grados de rueda en centímetros.

Misión: antes del aterrizaje hay que medir el largo de la pista. El robot avanza desde el inicio hasta tocar la pared del fondo (sensor de contacto en el puerto 1) e informa la distancia recorrida.

En una vuelta completa (360°) la rueda avanza lo que mide su circunferencia: π × diámetro. Por eso: cm = grados / 360 × π × diámetro.

src/MedirPista.java
import lejos.nxt.*;

public class MedirPista {
    public static void main(String[] args) {
        TouchSensor tacto = new TouchSensor(SensorPort.S1);
        double diametro = 5.6;   // diametro de la rueda en cm (medir)

        LCD.drawString("Medir pista", 0, 0);
        Button.waitForAnyPress();

        Motor.B.resetTachoCount();
        Motor.B.setSpeed(250);
        Motor.C.setSpeed(250);
        Motor.B.forward();
        Motor.C.forward();

        while (!tacto.isPressed()) {
            // avanzar hasta tocar la pared
        }
        Motor.B.stop(true);
        Motor.C.stop();

        int grados = Motor.B.getTachoCount();
        double cm = grados / 360.0 * Math.PI * diametro;

        LCD.clear();
        LCD.drawString("Grados: " + grados, 0, 0);
        LCD.drawString("Cm: " + (int) cm, 0, 2);
        Sound.beep();
        Button.waitForAnyPress();
    }
}

Desafíos

  1. Medir la pista con una cinta métrica y comparar. ¿De dónde puede venir la diferencia?
  2. Después de medir, volver al punto de partida retrocediendo exactamente los mismos grados.

Clase 8 · Preparar la zona de aterrizaje

45 minGuía: Pantalla, botones y sonido

Objetivos: controlar un tercer motor (pinza o brazo) con los botones y combinarlo con el movimiento.

Misión: hay que despejar la zona de aterrizaje moviendo rocas pequeñas fuera de un círculo marcado. Se agrega al robot una pinza o brazo con un motor en el puerto A (B y C siguen siendo las ruedas).

src/Pinza.java
import lejos.nxt.*;

public class Pinza {
    public static void main(String[] args) {
        Motor.A.setSpeed(100);
        int boton = 0;

        while (boton != Button.ID_ESCAPE) {
            LCD.clear();
            LCD.drawString("Control pinza", 0, 0);
            LCD.drawString("ENTER: cerrar", 0, 2);
            LCD.drawString("<    : abrir", 0, 3);
            LCD.drawString(">    : avanzar", 0, 4);
            LCD.drawString("ESC  : salir", 0, 6);

            boton = Button.waitForAnyPress();
            if (boton == Button.ID_ENTER) {
                Motor.A.rotate(90);           // cerrar (ajustar el angulo)
                Sound.beep();
            } else if (boton == Button.ID_LEFT) {
                Motor.A.rotate(-90);          // abrir
                Sound.twoBeeps();
            } else if (boton == Button.ID_RIGHT) {
                Motor.B.rotate(360, true);    // avanzar una vuelta
                Motor.C.rotate(360);
            }
        }
    }
}

Desafíos

  1. Ajustar el ángulo de la pinza para que agarre sin forzar el motor.
  2. Programar una secuencia automática: avanzar hasta la roca (ultrasónico), cerrar la pinza, girar 180°, avanzar y soltar.

Clases 9 y 10 · Proyecto final

2 × 45 minGuía: Proyectos sugeridos

Objetivo: diseñar, programar y presentar un desafío propio que integre motores, sensores y métodos.

Opciones de proyecto

  • Seguidor de línea que recorre una pista hasta la base (tema Sensor de luz).
  • Sistema de alarma que vigila la nave con el ultrasónico y suena si algo se acerca.
  • Robot bailarín con una coreografía y melodía programadas (arrays de notas y movimientos).
  • Explorador autónomo completo con comportamientos (tema Comportamientos).
  • Una propuesta propia del equipo, aprobada por la docente.

Clase 9: elegir el proyecto, escribir en papel qué tiene que hacer el robot (pasos o diagrama), y empezar a programar a partir de la plantilla. Clase 10: terminar, probar y presentar (demostración de 3 minutos y explicación del código).

        LCD.drawString("MI PROYECTO:", 0, 0);

        }
