Antes de empezar

Esta guía supone el entorno ya instalado y funcionando, según la guía Programar el NXT en Java con leJOS y VS Code: proyecto en VS Code, NXT emparejado por Bluetooth y Ctrl + Shift + B para compilar, subir y ejecutar.

01

Estructura de un programa

Todo programa para el NXT es una clase de Java con un método main, que es el punto donde empieza la ejecución. Antes de la clase se importan las clases de leJOS que se van a usar: motores, sensores, pantalla, etc.

src/HolaMundo.java
import lejos.nxt.LCD;
import lejos.util.Delay;

public class HolaMundo {
    public static void main(String[] args) {
        // escribe en la columna 0, fila 0 de la pantalla
        LCD.drawString("Hola NXT!", 0, 0);

        // espera 5 segundos para poder leer el mensaje
        Delay.msDelay(5000);
    }
}
  • Imports: se puede importar cada clase (import lejos.nxt.LCD;) o todo un paquete (import lejos.nxt.*;). Las clases más usadas están en lejos.nxt; Delay está en lejos.util.
  • Pausas: Delay.msDelay(ms) detiene el programa la cantidad de milisegundos indicada. A diferencia de Thread.sleep(), no obliga a usar try/catch.
  • Fin del programa: cuando main termina, el NXT vuelve al menú de leJOS. Por eso los ejemplos esperan un tiempo o un botón antes de terminar.
  • Pantalla: tiene 16 columnas (0 a 15) y 8 filas (0 a 7) y no muestra tildes ni eñes.

Para crear un programa nuevo: agregar un archivo .java en la carpeta src, con el mismo nombre que la clase, tenerlo abierto en el editor y presionar Ctrl + Shift + B.

Ejercicios

  1. Modificar HolaMundo para que muestre un nombre en la fila 0 y el grupo en la fila 2.
  2. Mostrar un mensaje durante 3 segundos, borrar la pantalla con LCD.clear() y mostrar otro mensaje durante 3 segundos más.
02

Pantalla, botones y sonido

El brick tiene una pantalla, cuatro botones y un parlante. Las clases LCD, Button y Sound permiten usarlos.

MétodoQué hace
LCD.drawString(texto, col, fila)Escribe un texto.
LCD.drawInt(numero, col, fila)Escribe un número entero.
LCD.clear()Borra toda la pantalla.
Button.waitForAnyPress()Espera que se presione un botón y devuelve cuál fue: Button.ID_ENTER, ID_LEFT, ID_RIGHT o ID_ESCAPE.
Button.ESCAPE.isDown()Devuelve true mientras el botón está presionado, sin esperar. Existe también para ENTER, LEFT y RIGHT.
Sound.beep() / Sound.buzz()Pitido corto / zumbido grave.
Sound.playTone(frecuencia, ms)Toca una nota: frecuencia en Hz, duración en milisegundos.

Ejemplo: un contador que sube con el botón derecho, baja con el izquierdo y termina con ESCAPE.

src/Contador.java
import lejos.nxt.Button;
import lejos.nxt.LCD;
import lejos.nxt.Sound;

public class Contador {
    public static void main(String[] args) {
        int valor = 0;
        int boton = 0;

        while (boton != Button.ID_ESCAPE) {
            LCD.clear();
            LCD.drawString("Contador:", 0, 0);
            LCD.drawInt(valor, 0, 2);
            LCD.drawString("ESC para salir", 0, 6);

            boton = Button.waitForAnyPress();
            if (boton == Button.ID_RIGHT) {
                valor++;
                Sound.beep();
            } else if (boton == Button.ID_LEFT) {
                valor--;
                Sound.buzz();
            }
        }
    }
}

En leJOS, System.out.println() también escribe en la pantalla del NXT, línea por línea y desplazando el texto hacia arriba. Es útil para mostrar mensajes de seguimiento.

Ejercicios

  1. Agregar al contador que con ENTER vuelva a 0.
  2. Hacer que el contador no baje de 0 ni suba de 10, y que emita Sound.buzz() al intentar pasarse.
  3. Tocar una escala con Sound.playTone(): por ejemplo, 262, 294, 330, 349, 392, 440, 494 y 523 Hz, 300 ms cada nota.

03

Motores

Los motores se conectan en los puertos A, B y C, y se controlan con Motor.A, Motor.B y Motor.C. En los ejemplos, el robot tiene la rueda izquierda en B y la derecha en C.

MétodoQué hace
setSpeed(gradosPorSegundo)Velocidad. Con pilas cargadas, el máximo ronda los 700–900.
forward() / backward()Gira hacia adelante / atrás sin detenerse, hasta recibir otra orden.
stop()Frena el motor y espera a que se detenga.
stop(true)Frena el motor sin esperar: permite frenar dos motores casi a la vez.
rotate(grados)Gira esa cantidad de grados (360 = una vuelta de rueda) y espera a terminar.
rotate(grados, true)Igual, pero sin esperar: el programa sigue a la línea siguiente.
getTachoCount()Grados girados desde el inicio (el motor tiene un sensor de rotación incorporado).

Movimiento por tiempo con forward(), backward() y stop():

src/MoverYGirar.java
import lejos.nxt.Motor;
import lejos.util.Delay;

public class MoverYGirar {
    public static void main(String[] args) {
        Motor.B.setSpeed(400);
        Motor.C.setSpeed(400);

        System.out.println("Avanzando");
        Motor.B.forward();
        Motor.C.forward();
        Delay.msDelay(2000);

        System.out.println("Frenando");
        Motor.B.stop(true);       // no espera: frena B y sigue
        Motor.C.stop();           // espera a que C se detenga
        Delay.msDelay(500);

        System.out.println("Girando");
        Motor.B.forward();        // una rueda adelante...
        Motor.C.backward();       // ...y la otra atras: gira en el lugar
        Delay.msDelay(1000);

        Motor.B.stop(true);
        Motor.C.stop();
    }
}

Movimiento por ángulo con rotate(): más preciso que por tiempo, porque no depende de la carga de las pilas.

fragmento
Motor.B.rotate(720, true);   // true: arranca B y sigue sin esperar
Motor.C.rotate(720);         // arranca C y espera: las dos ruedas giran juntas

Si se usara rotate(720) en los dos motores, primero giraría uno y después el otro, y el robot avanzaría torcido.

Ejercicios

  1. Hacer que el robot avance 2 segundos, retroceda 2 segundos y emita un pitido.
  2. Usando rotate(), encontrar cuántos grados de rueda hacen falta para que el robot gire 90°. Anotar el valor: se usa en los próximos temas.
  3. Recorrer un cuadrado con un for de 4 repeticiones.
  4. Mostrar en pantalla el valor de Motor.B.getTachoCount() antes y después de avanzar.
04

Clase auxiliar con métodos propios

Cuando los mismos movimientos se repiten en varios programas, conviene agruparlos en una clase auxiliar con métodos de nombres simples. Primero se usan los métodos (Robot.avanzar(720)) y después se analiza cómo está hecho cada uno.

Nombre de la clase

No llamarla NXT: leJOS ya tiene una clase lejos.nxt.NXT y el nombre se presta a confusión.

src/Robot.java
import lejos.nxt.Button;
import lejos.nxt.LCD;
import lejos.nxt.Motor;

public class Robot {

    public static void velocidad(int gradosPorSegundo) {
        Motor.B.setSpeed(gradosPorSegundo);
        Motor.C.setSpeed(gradosPorSegundo);
    }

    // gradosRueda: cuanto gira cada rueda (360 = una vuelta)
    public static void avanzar(int gradosRueda) {
        Motor.B.rotate(gradosRueda, true);
        Motor.C.rotate(gradosRueda);
    }

    public static void retroceder(int gradosRueda) {
        avanzar(-gradosRueda);
    }

    // las ruedas giran en sentidos opuestos: el robot gira en el lugar
    public static void girarDerecha(int gradosRueda) {
        Motor.B.rotate(gradosRueda, true);
        Motor.C.rotate(-gradosRueda);
    }

    public static void girarIzquierda(int gradosRueda) {
        girarDerecha(-gradosRueda);
    }

    public static void mostrar(String texto, int fila) {
        LCD.drawString(texto, 0, fila);
    }

    public static void esperarBoton() {
        Button.waitForAnyPress();
    }
}

Un programa que usa la clase auxiliar:

src/Cuadrado.java
public class Cuadrado {
    public static void main(String[] args) {
        Robot.mostrar("Cuadrado", 0);
        Robot.esperarBoton();
        Robot.velocidad(300);

        for (int lado = 1; lado <= 4; lado++) {
            Robot.avanzar(720);
            Robot.girarDerecha(180);   // ajustar hasta lograr 90 grados
        }
        Robot.mostrar("Fin", 2);
        Robot.esperarBoton();
    }
}

Guardar los dos archivos en src, abrir Cuadrado.java (el que tiene el main) y presionar Ctrl + Shift + B. Robot.java se compila sola.

Ejercicios

  1. Agregar a Robot un método girar90Derecha() que use el valor encontrado en el tema de motores.
  2. Agregar un método poligono(int lados) que recorra un polígono regular (pista: el giro total es 360°, repartido entre los lados).
  3. Dibujar un triángulo y un hexágono con poligono().
05

Navegación con DifferentialPilot

DifferentialPilot controla las dos ruedas juntas y permite indicar distancias en centímetros y giros en grados del robot, en lugar de grados de rueda. Necesita dos medidas del robot: el diámetro de la rueda y la distancia entre las dos ruedas.

MétodoQué hace
setTravelSpeed(cmPorSegundo)Velocidad de avance.
travel(cm)Avanza (o retrocede, con valor negativo) esa distancia.
rotate(grados)Gira el robot en el lugar.
arc(radio, grados)Avanza describiendo un arco.
forward() / stop()Avanza sin parar / se detiene.

Ejemplo: explorador que esquiva obstáculos con el sensor ultrasónico en el puerto 4. Se detiene con el botón gris oscuro (ESCAPE).

src/Explorador.java
import lejos.nxt.*;
import lejos.robotics.navigation.DifferentialPilot;

public class Explorador {
    public static void main(String[] args) {
        // diametro de rueda y distancia entre ruedas, en cm (medir el robot)
        DifferentialPilot piloto =
            new DifferentialPilot(5.6, 11.2, Motor.B, Motor.C);
        UltrasonicSensor sonar = new UltrasonicSensor(SensorPort.S4);

        piloto.setTravelSpeed(15);       // cm por segundo
        LCD.drawString("Explorador", 0, 0);
        Button.waitForAnyPress();

        while (!Button.ESCAPE.isDown()) {
            if (sonar.getDistance() < 25) {
                piloto.stop();
                Sound.beep();
                piloto.travel(-10);       // retrocede 10 cm
                piloto.rotate(90);        // gira 90 grados
            } else {
                piloto.forward();
            }
        }
        piloto.stop();
    }
}

Si el robot gira de más o de menos, ajustar la distancia entre ruedas (11.2); si avanza de más o de menos, ajustar el diámetro (5.6).

Ejercicios

  1. Calibrar el piloto: pedir travel(50) y medir con una regla cuánto avanzó realmente; pedir rotate(360) y ver si da una vuelta exacta.
  2. Recorrer un rectángulo de 40 × 20 cm con travel() y rotate().
  3. Dibujar un círculo con arc().

06

Sensores: contacto y ultrasónico

Para usar un sensor se crea un objeto de su clase indicando el puerto donde está conectado: SensorPort.S1 a SensorPort.S4.

Sensor de contacto (TouchSensor): isPressed() devuelve true mientras está presionado. Ejemplo: avanzar hasta chocar.

src/DetectorToque.java
import lejos.nxt.*;

public class DetectorToque {
    public static void main(String[] args) {
        TouchSensor tacto = new TouchSensor(SensorPort.S1);

        Motor.B.forward();
        Motor.C.forward();

        while (!tacto.isPressed()) {
            // repetir hasta que el sensor se presione
        }

        Motor.B.stop(true);
        Motor.C.stop();
        Sound.beep();
        Button.waitForAnyPress();
    }
}

Sensor ultrasónico (UltrasonicSensor): getDistance() devuelve la distancia al objeto más cercano en centímetros (255 si no detecta nada). Ejemplo: avanzar hasta quedar a 25 cm de un obstáculo.

src/FrenarAntesDeChocar.java
import lejos.nxt.*;

public class FrenarAntesDeChocar {
    public static void main(String[] args) {
        UltrasonicSensor sonar = new UltrasonicSensor(SensorPort.S4);

        Motor.B.forward();
        Motor.C.forward();

        while (sonar.getDistance() > 25) {
            LCD.drawString("Dist:    ", 0, 0);
            LCD.drawInt(sonar.getDistance(), 6, 0);
        }

        Motor.B.stop(true);
        Motor.C.stop();
        Sound.buzz();
        Button.waitForAnyPress();
    }
}

Los while de estos ejemplos repiten la consulta al sensor una y otra vez hasta que se cumple la condición: es la forma más simple de "esperar" a que pase algo.

Ejercicios

  1. Al chocar, retroceder 1 segundo, girar y volver a avanzar. Repetir hasta presionar ESCAPE.
  2. Hacer un "sensor de estacionamiento": pitidos más rápidos cuanto más cerca está el obstáculo (pista: Delay.msDelay(distancia * 10) entre pitido y pitido).
  3. Hacer que el robot mantenga una distancia de 20 cm con una mano que se acerca y se aleja: avanzar si está lejos, retroceder si está cerca.
07

Sensor de luz y seguidor de línea

LightSensor mide la luz reflejada por la superficie que tiene debajo: getLightValue() devuelve un valor aproximado entre 0 (oscuro) y 100 (claro). Al crearlo, enciende su luz roja para iluminar el piso.

Paso 1: medir. Los valores dependen del piso, la cinta y la iluminación del aula, así que primero hay que medirlos. Este programa muestra el valor en pantalla: apoyar el sensor sobre la línea negra y sobre el fondo blanco, y anotar los dos números.

src/MedirLuz.java
import lejos.nxt.*;

public class MedirLuz {
    public static void main(String[] args) {
        LightSensor luz = new LightSensor(SensorPort.S3);

        while (!Button.ESCAPE.isDown()) {
            LCD.drawString("Luz:    ", 0, 0);
            LCD.drawInt(luz.getLightValue(), 5, 0);
        }
    }
}

Paso 2: seguir la línea. El umbral es el punto medio entre los dos valores medidos: por ejemplo, si el negro da 35 y el blanco 55, el umbral es 45. El robot sigue el borde de la línea: si ve negro, dobla hacia un lado; si ve blanco, dobla hacia el otro. Así avanza zigzagueando sobre el borde.

src/SeguidorDeLinea.java
import lejos.nxt.*;

public class SeguidorDeLinea {
    public static void main(String[] args) {
        LightSensor luz = new LightSensor(SensorPort.S3);
        int umbral = 45;           // (negro + blanco) / 2, con los valores medidos

        LCD.drawString("Seguidor", 0, 0);
        Button.waitForAnyPress();
        Motor.B.forward();
        Motor.C.forward();

        while (!Button.ESCAPE.isDown()) {
            if (luz.getLightValue() < umbral) {
                // sobre la linea negra: doblar hacia afuera
                Motor.B.setSpeed(250);
                Motor.C.setSpeed(80);
            } else {
                // sobre el fondo blanco: doblar hacia la linea
                Motor.B.setSpeed(80);
                Motor.C.setSpeed(250);
            }
        }
        Motor.B.stop(true);
        Motor.C.stop();
    }
}

Si el robot se escapa de la línea en las curvas, bajar las velocidades. Si se aleja de la línea en lugar de seguirla, intercambiar las velocidades de los dos casos (está siguiendo el otro borde).

Ejercicios

  1. Mostrar en pantalla, mientras sigue la línea, si el sensor ve "NEGRO" o "BLANCO".
  2. Detener el robot cuando el sensor ultrasónico detecta un obstáculo en la línea y continuar cuando se retira.
  3. Desafío: seguidor proporcional. En lugar de dos velocidades fijas, calcular error = luz - umbral y usar 200 + error * 5 para un motor y 200 - error * 5 para el otro. Comparar qué tan suave es el recorrido.

08

Comportamientos (Behavior y Arbitrator)

Cuando un robot tiene que hacer varias cosas (avanzar, esquivar, detenerse), los if anidados se vuelven difíciles de leer. La programación por comportamientos divide el problema: cada comportamiento es una clase que implementa la interfaz Behavior, y un Arbitrator decide cuál actúa en cada momento.

Método de BehaviorQué debe hacer
takeControl()Devolver true cuando el comportamiento quiere actuar (por ejemplo, si el sensor está presionado).
action()Lo que hace el robot cuando el comportamiento tiene el control.
suppress()Detener action() cuando otro comportamiento más importante toma el control.
Prioridad

En el array que recibe el Arbitrator, el último comportamiento es el de mayor prioridad y el primero, el de menor. Si dos quieren actuar a la vez, gana el que está más al final.

Ejemplo: el robot avanza; si choca, retrocede y gira; con ESCAPE termina el programa. Las cuatro clases van en el mismo archivo (solo la que tiene el main es public).

src/RobotConComportamientos.java
import lejos.nxt.*;
import lejos.robotics.subsumption.*;
import lejos.util.Delay;

// Comportamiento 1 (prioridad baja): avanzar
class Avanzar implements Behavior {
    private boolean suprimido = false;

    public boolean takeControl() {
        return true;                 // siempre quiere avanzar
    }

    public void action() {
        suprimido = false;
        Motor.B.forward();
        Motor.C.forward();
        while (!suprimido) {
            Thread.yield();          // espera sin bloquear a los demas
        }
        Motor.B.stop(true);
        Motor.C.stop();
    }

    public void suppress() {
        suprimido = true;
    }
}

// Comportamiento 2 (prioridad media): esquivar al chocar
class Esquivar implements Behavior {
    private TouchSensor tacto;

    public Esquivar(SensorPort puerto) {
        tacto = new TouchSensor(puerto);
    }

    public boolean takeControl() {
        return tacto.isPressed();
    }

    public void action() {
        Motor.B.backward();          // retroceder 1 segundo
        Motor.C.backward();
        Delay.msDelay(1000);
        Motor.B.stop(true);          // detener los dos antes de girar
        Motor.C.stop();
        Motor.B.rotate(360, true);   // girar en el lugar
        Motor.C.rotate(-360);
    }

    public void suppress() {
        // action() es corta: no hace falta interrumpirla
    }
}

// Comportamiento 3 (prioridad alta): terminar con ESCAPE
class Salir implements Behavior {
    public boolean takeControl() {
        return Button.ESCAPE.isDown();
    }

    public void action() {
        System.exit(0);
    }

    public void suppress() { }
}

public class RobotConComportamientos {
    public static void main(String[] args) {
        Behavior avanzar = new Avanzar();
        Behavior esquivar = new Esquivar(SensorPort.S1);
        Behavior salir = new Salir();

        // de menor a mayor prioridad
        Behavior[] comportamientos = { avanzar, esquivar, salir };

        Arbitrator arbitro = new Arbitrator(comportamientos);
        arbitro.start();
    }
}

Este patrón se relaciona directamente con POO: cada comportamiento es una clase que implementa una interfaz, y el Arbitrator los maneja a todos de la misma forma, como objetos de tipo Behavior (polimorfismo).

Ejercicios

  1. Agregar un comportamiento EsquivarConSonar que gire cuando el sensor ultrasónico detecta algo a menos de 20 cm. Decidir en qué posición del array va.
  2. Cambiar el orden del array (poner avanzar al final) y observar qué pasa. Explicar por qué.
  3. Pasar cada comportamiento a su propio archivo .java como clase public.

Proyectos sugeridos

Proyectos para integrar lo visto. Conviene resolverlos en etapas: primero un movimiento básico, después agregar sensores y por último mejorar la precisión.

ProyectoQué integra
Robot explorador: recorre el aula sin chocar, esquivando con el sensor ultrasónico y con el de contacto como respaldo.Sensores, DifferentialPilot, comportamientos.
Seguidor de línea con paradas: sigue una pista y se detiene unos segundos al encontrar una marca (por ejemplo, una zona más oscura) o un obstáculo.Sensor de luz, ultrasónico, calibración.
Laberinto simple: sale de un laberinto armado con cajas siguiendo la regla de la mano derecha (girar a la derecha cuando se puede, a la izquierda cuando hay pared).Ultrasónico, contacto, toma de decisiones.
Robot dibujante: con un marcador sujeto al robot, dibuja polígonos regulares elegidos con los botones (cantidad de lados en pantalla, ENTER para dibujar).Botones, pantalla, clase auxiliar, for.
Alarma de proximidad: queda quieto vigilando y suena una melodía si alguien se acerca a menos de 50 cm; se desactiva con una secuencia de botones.Ultrasónico, sonido, botones, estados.

Para consultar todos los métodos disponibles: la documentación de la API instalada con leJOS, en C:\Program Files (x86)\leJOS NXJ\docs, y los ejemplos en la carpeta samples.
