Estado de esta guía

Esta guía está armada a partir de la documentación de leJOS y de la experiencia en Windows, pero todavía no se probó en la sala. Al probarla, anotar cualquier paso que falle o cambie para corregirla.

Para qué sirve

  • Programar el NXT en Java desde computadoras con Ubuntu (probado como objetivo: Ubuntu 22.04 y 24.04).
  • Conectar por USB, que en Linux no depende del driver Fantom de Windows.
  • Usar una computadora con Linux como estación para instalar el firmware leJOS en los NXT.

No cubre Bluetooth en Linux (las computadoras de la sala no lo tienen). Para Windows, ver la guía Programar el NXT en Java con leJOS y VS Code.

↑ índiceInstalación

01

Instalar Java 8 y las herramientas de compilación

Abrir una terminal (Ctrl + Alt + T) y ejecutar:

Terminal
sudo apt update
sudo apt install openjdk-8-jdk ant build-essential libusb-dev
  • openjdk-8-jdk: el JDK que usa leJOS. En Linux no hace falta que sea de 32 bits: la parte nativa de leJOS se compila en la misma computadora (paso 4).
  • ant, build-essential y libusb-dev: necesarios para compilar el acceso USB de leJOS.

Si la computadora ya tiene otro Java (por ejemplo, el 17), no se modifica: leJOS va a usar el 8 mediante una variable propia.

Terminal · verificar
ls /usr/lib/jvm/        # debe aparecer java-8-openjdk-amd64
02

Descargar e instalar leJOS NXJ

leJOS para Linux viene en un archivo .tar.gz (no en un instalador). Este bloque lo descarga de SourceForge y lo descomprime en /opt/leJOS_NXJ:

Terminal
cd ~/Descargas
wget -O leJOS_NXJ_0.9.1beta-3.tar.gz "https://sourceforge.net/projects/lejos/files/lejos-NXJ/0.9.1beta/leJOS_NXJ_0.9.1beta-3.tar.gz/download"

sudo mkdir -p /opt/leJOS_NXJ
sudo tar -xzf leJOS_NXJ_0.9.1beta-3.tar.gz -C /opt/leJOS_NXJ --strip-components=1
sudo chown -R $USER:$USER /opt/leJOS_NXJ
chmod +x /opt/leJOS_NXJ/bin/*

Comprobar que el archivo descargado pese unos 21 MB y que ls /opt/leJOS_NXJ muestre carpetas como bin, lib y build. Si la carpeta de descargas se llama Downloads, cambiar la primera línea.

Recomendado

Guardar también este .tar.gz en el release instaladores-nxt del repositorio NXT-java, por si desaparece de SourceForge.

03

Configurar las variables de entorno

Agregar las variables al final de ~/.bashrc y cargarlas:

Terminal
cat >> ~/.bashrc <<'EOF'

# leJOS NXJ (LEGO NXT)
export NXJ_HOME=/opt/leJOS_NXJ
export LEJOS_NXT_JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
export PATH="$NXJ_HOME/bin:$PATH"
EOF

source ~/.bashrc
nxjc -version          # debe mostrar javac 1.8.0_...

Como en Windows, LEJOS_NXT_JAVA_HOME hace que leJOS use Java 8 sin cambiar el Java del resto del sistema.

04

Compilar el acceso USB de leJOS

leJOS necesita una pequeña librería nativa para comunicarse por USB, que se compila una sola vez:

Terminal
cd $NXJ_HOME/build
JAVA_HOME=$LEJOS_NXT_JAVA_HOME ant
Listo si

Al final aparece BUILD SUCCESSFUL. Si aparece un error que menciona usb.h, falta el paquete libusb-dev (paso 1).

05

Dar permiso de acceso al NXT por USB

Por defecto, Linux solo deja usar dispositivos USB desconocidos al administrador. Esta regla da acceso al NXT a todos los usuarios, tanto en modo normal como en modo de actualización de firmware:

Terminal
sudo tee /etc/udev/rules.d/70-lego-nxt.rules > /dev/null <<'EOF'
# LEGO NXT en modo normal
SUBSYSTEM=="usb", ATTRS{idVendor}=="0694", ATTRS{idProduct}=="0002", MODE="0666"
# LEGO NXT en modo de actualizacion de firmware
SUBSYSTEM=="usb", ATTRS{idVendor}=="03eb", ATTRS{idProduct}=="6124", MODE="0666", ENV{ID_MM_DEVICE_IGNORE}="1"
EOF

sudo udevadm control --reload-rules
sudo udevadm trigger

ID_MM_DEVICE_IGNORE evita que el administrador de módems de Ubuntu tome el NXT mientras se instala el firmware. Desconectar y volver a conectar el NXT después de crear la regla.

06

Verificar la conexión

Con el NXT encendido y conectado por USB:

Terminal
lsusb | grep -i lego   # debe aparecer "LEGO Group"
nxjbrowse              # abre la lista de archivos del NXT

Si nxjbrowse muestra el NXT con protocolo USB, la instalación está completa.

↑ índiceFirmware leJOS

07

Instalar el firmware leJOS en los NXT

Si el USB funciona en Linux, esta computadora puede ser la estación para instalar el firmware en todos los NXT. Después, los estudiantes pueden programarlos por Bluetooth desde las Ceibalitas.

El procedimiento y los cuidados son los mismos que en Windows (ver la guía de Windows, paso 6): se borran los programas guardados y el NXT deja de funcionar con Open Roberta hasta reinstalar el firmware de LEGO.

Terminal
nxjflashg              # versión con ventana
# o bien, en la terminal:
nxjflash

Si el programa lo pide, poner el NXT en modo de actualización: presionar con un clip el botón de reset (en el orificio de atrás, junto al puerto USB) durante más de 4 segundos, hasta que haga tictac.

↑ índiceProyecto en VS Code

08

Instalar VS Code y la extensión de Java

Terminal
sudo snap install code --classic
code --install-extension vscjava.vscode-java-pack

Si no se puede usar snap, descargar el paquete .deb desde code.visualstudio.com e instalarlo con sudo apt install ./code_*.deb desde la carpeta de descargas.

09

Crear el proyecto

Este script crea la carpeta ~/nxt-hola con la configuración y el primer programa, y la abre en VS Code. Se diferencia del de Windows en las rutas y en que sube por USB (-u). Las tareas definen sus propias variables de entorno, así funcionan aunque VS Code se abra desde el menú y no desde la terminal.

Terminal
mkdir -p ~/nxt-hola/.vscode ~/nxt-hola/nxt-bin ~/nxt-hola/src
cd ~/nxt-hola

cat > .vscode/settings.json <<'EOF'
{
  "java.project.sourcePaths": ["src"],
  "java.project.referencedLibraries": [
    "/opt/leJOS_NXJ/lib/nxt/classes.jar"
  ]
}
EOF

cat > .vscode/tasks.json <<'EOF'
{
  "version": "2.0.0",
  "options": {
    "env": {
      "NXJ_HOME": "/opt/leJOS_NXJ",
      "LEJOS_NXT_JAVA_HOME": "/usr/lib/jvm/java-8-openjdk-amd64",
      "PATH": "/opt/leJOS_NXJ/bin:${env:PATH}"
    }
  },
  "tasks": [
    {
      "label": "NXT: Compilar",
      "type": "shell",
      "command": "nxjc -d nxt-bin -sourcepath src \"${file}\"",
      "problemMatcher": []
    },
    {
      "label": "NXT: Subir y ejecutar",
      "type": "shell",
      "command": "nxj -u -r -cp nxt-bin ${fileBasenameNoExtension}",
      "dependsOn": "NXT: Compilar",
      "group": { "kind": "build", "isDefault": true },
      "problemMatcher": []
    },
    {
      "label": "NXT: Solo subir",
      "type": "shell",
      "command": "nxj -u -cp nxt-bin ${fileBasenameNoExtension}",
      "dependsOn": "NXT: Compilar",
      "problemMatcher": []
    }
  ]
}
EOF

cat > src/HolaNXT.java <<'EOF'
import lejos.nxt.Button;
import lejos.nxt.LCD;
import lejos.nxt.Sound;

public class HolaNXT {
    public static void main(String[] args) {
        LCD.drawString("Hola desde Linux", 0, 0);
        Sound.beep();
        Button.waitForAnyPress();
    }
}
EOF

code .

Abrir src/HolaNXT.java y presionar Ctrl + Shift + B. A partir de acá, todo funciona igual que en Windows y se puede seguir con la guía Programar el NXT en Java: primeros pasos.

Problemas frecuentes

Si algo no funciona

«nxjc: orden no encontrada»
Las variables no se cargaron. Ejecutar source ~/.bashrc o abrir una terminal nueva (paso 3).
«Failed to load USB comms driver»
La librería USB no se compiló. Repetir el paso 4 y revisar que termine con BUILD SUCCESSFUL.
«Permission denied» o el NXT no aparece en nxjbrowse
Revisar la regla del paso 5, desconectar y volver a conectar el NXT. Comprobar con lsusb que el sistema lo detecta.
La instalación del firmware se queda esperando
Comprobar que el NXT esté en modo de actualización (pantalla en blanco y tictac) y que la regla incluya ID_MM_DEVICE_IGNORE. Desconectar y volver a conectar el cable.
VS Code no encuentra nxjc al presionar Ctrl + Shift + B
Revisar que tasks.json tenga la sección options.env con las rutas correctas.
